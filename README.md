# DS Algo

## 📌 About

This repository is a collection of **important Data Structures and Algorithms**, along with their theory, explanations, implementations, and examples.

The purpose of this repository is to build a **personal reference guide** for DSA — something I can come back to whenever I need to learn, revise, or recall an algorithm or concept.

---

## 🎯 Motive

While learning DSA, it is easy to understand an algorithm once and then forget its intuition, approach, or implementation later.

Instead of repeatedly searching through different websites, notes, and videos, this repository aims to keep the important concepts in **one organized place**.

For every important algorithm, the focus will be on:

* Understanding the **core idea**
* Knowing **why** the algorithm works
* Going through some **example**
* Understanding the **implementation**
* Knowing its **time and space complexity**
* Keeping track of important **variations and applications**

The goal is not to memorize algorithms, but to develop the ability to **recognize a problem, identify the appropriate approach, and implement it correctly**.

---

## 💡 Why this repository?

DSA is not just about solving individual problems. Many problems are based on a relatively small number of fundamental **patterns and techniques**.

This repository is an attempt to document those patterns and algorithms in a way that makes them easier to:

* Learn
* Revise
* Recall
* Apply to new problems

It will also serve as a record of my **progress and learning journey in DSA**.

---

## 🛠️ What you'll find here

The repository will contain:

* 🧠 Algorithmic intuition
* 💻 C++ implementations

* ⏱️ Time & space complexity
